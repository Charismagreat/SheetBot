# SheetBot 사용자 가이드 및 운영 매뉴얼

구글 스프레드시트 기반의 Google Apps Script AI 자동화 SaaS 플랫폼 **SheetBot**의 사용자 가이드입니다.

---

## 1. 서비스 개요
SheetBot은 복잡한 Google Apps Script(GAS) 코딩 없이, 자연어 요구사항만으로 스프레드시트 자동화 프로젝트를 만들고, 클라우드 스케줄(트리거)을 등록하여 정기 실행할 수 있는 지능형 자동화 SaaS입니다.

---

## 2. 주요 기능 및 사용 방법

### 2.1 구글 계정 1초 로그인
- **Google OAuth 연동**: 회원가입 절차 없이 사용자의 구글 계정으로 로그인합니다.
- **데모 체험 모드**: 개발 및 테스트 환경에서는 데모 계정으로 즉시 체험이 가능합니다.
- **회원별 데이터 격리**: 로그인된 구글 이메일 단위로 모든 프로젝트와 스케줄이 완벽히 분리되어 안전하게 보호됩니다.

### 2.2 AI Apps Script 프로젝트 생성
1. 대시보드 우측 상단의 **[+ 새 프로젝트 생성]** 버튼을 클릭합니다.
2. 대상 **구글 스프레드시트 URL** 또는 시트 ID를 입력합니다.
3. 원하는 자동화 요구사항을 자연어로 입력합니다. (예: *"매일 오전 9시에 A열의 상태가 '대기'인 주문 건을 B열의 거래처로 이메일 전송하고 상태를 '완료'로 변경"*).
4. **[🚀 AI 스크립트 생성 및 시트 배포]**를 클릭하면, 이지데스크 AI Caller가 `Code.gs`와 `appsscript.json`을 자동 생성하고 대상 스프레드시트에 직접 바인딩하여 클라우드에 배포합니다.
5. 구글 시트를 열면 상단에 `🚀 SheetBot 자동화` 메뉴가 생성되어 즉시 실행할 수 있습니다.

### 2.3 자동화 스케줄 및 트리거 관리
1. 프로젝트 카드의 **[스케줄 관리]** 버튼을 클릭합니다.
2. **트리거 유형 선택**:
   - **시간 기반(TIME_DRIVEN)**: 분, 시간, 일, 주 단위 정기 실행 설정 (예: 매일 09시 실행)
   - **이벤트 기반(EVENT_DRIVEN)**: 시트 수정(`onEdit`), 시트 열기(`onOpen`), 설문지 제출(`onFormSubmit`) 등 이벤트 감지 트리거
3. **스케줄 제어**:
   - **활성/일시정지 토글**: 원클릭으로 스케줄 활성화 상태를 제어합니다.
   - **즉시 실행(Run Now)**: 클라우드에 배포된 스크립트 함수를 원격으로 즉각 테스트 실행하고 결과를 확인합니다.

### 2.4 AI 도움말 (Contextual Help) 활용
- 대시보드의 주요 버튼, 입력란, 상태 뱃지에 마우스를 1초간 올려놓으면 AI가 해당 항목의 상세 가이드와 실무 팁을 담은 팝업을 즉시 띄워줍니다.
- 상단 네비게이션 바의 **[AI 도움말]** 토글 단추를 통해 언제든지 도움말 팝업 표시를 켜거나 끌 수 있습니다.

### 2.5 이지봇 (EasyBot) 대화형 비서
- 화면 우측 하단의 **이지봇(EasyBot) 플로팅 버튼**을 클릭하여 대화창을 열 수 있습니다.
- 스프레드시트 수식(`VLOOKUP`, `QUERY` 등) 작성법, Apps Script 문법, 구글 시트 오류 해결법, 스케줄 설정 가이드를 실시간 자연어로 질문하고 해결책을 안내받을 수 있습니다.

---

## 3. 데이터 및 백엔드 인프라
- **이지데스크 My DB**: `sheetbot_projects`, `sheetbot_schedules` 테이블을 통해 소프트 삭제(Soft Delete) 및 7종 감사 이력을 관리합니다.
- **이지데스크 AI Caller**: 사내 중앙 통제 LLM 엔진을 경유하여 빠르고 안정적인 Apps Script 코드 생성과 AI 도움말을 제공합니다.
- **Apps Script MCP 도구**: 구글 클라우드와 원스톱 연동되어 바인딩 생성 및 원격 함수 실행을 수행합니다.
