## 🌐 3. 통합 호스팅 패스 포함 혜택 (All-in-One 6대 기능)

계정당 월 39,000원(390,000T) 결제 시 사장님이 사용하는 모든 앱과 기기에서 아래 6대 호스팅 기능이 동시 해금됩니다:

1. **📑 스마트 간편 견적서 웹 호스팅**:
   - 사장님 30초 견적 발행기 (`/estimate/issue`)
   - 고객 실시간 모바일 셀프 견적기 (`/estimate/[userKey]`)
   - 공인 전자 견적서 뷰어 (직인 날인, A4 인쇄/PDF 저장, 원터치 승인 추적)
2. **🛍️ 스마트 간편 주문 쇼핑몰 웹 호스팅**:
   - 모바일 상품 카탈로그 및 간편 주문서 (`/order/[userKey]`)
   - 고객 주문 확인서 웹페이지 (`/order/view/[orderId]`)
3. **📇 통화 종료 후 모바일 명함 랜딩페이지 호스팅**:
   - 고객 통화 후 자동 전송되는 모바일 웹 명함 및 포트폴리오
4. **⚖️ 전문 법률 검토 의견서 웹 리포트 호스팅**:
   - `egdesk-korean-law` 연동 판례/법률 검토 리포트 (`/reports/law/[id]`)
5. **🏢 기업 재무 / 나라장터 공공입찰 분석 대시보드 호스팅**:
   - `egdesk-company-research` 연동 기업 인텔리전스 리포트 (`/reports/company/[id]`)
6. **📝 블로그 원고 프리뷰 & 📸 인스타 카드뉴스 시뮬레이터 호스팅**:
   - 사전 검수용 웹 뷰어 및 스와이프 인터랙티브 뷰어

## 🔄 5. 자동 갱신 및 3일 안심 유예 정책 (Life Cycle)

1. **구독 활성화**: 390,000 토큰 차감 즉시 `hosting_expires_at: (현재 + 30일)` 부여.
2. **30일 주기 자동 갱신**: 만료일 자정에 백그라운드 워커가 390,000 토큰 차감 후 30일 연장.
3. **잔액 부족 시 3일 유예 기간 (Grace Period)**:
   - 만료 시 잔액이 부족해도 웹사이트를 즉시 차단하지 않고 **3일간 정상 서비스 유지**.
   - 사장님 앱으로 *"호스팅 유지를 위해 충전이 필요합니다 (D-2일)"* 푸시 알림 발송.
   - 충전 즉시 미납분 차감 후 정상 연장.
